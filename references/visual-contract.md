# 稻田品牌与交互约定

## 品牌源

- `assets/brand/company-logo.ai`：用户提供的原始矢量文件，原样保留。
- `assets/brand/company-logo.png`：从原始 Logo 渲染，用于 HTML 内嵌；不重新生成、拉伸、裁断或加滤镜。
- 主色 #1E3282，标志蓝 #132F8A；强调色 #E83B19，小字警示 #B82F14；次文字 #52618C，底色 #F5F7FB，边线 #D8DEEC。
- Logo 在白底品牌区展示。数字与正向变化用蓝色，负向变化或需要核查用橙色，同时保留文字 / 数值，不只靠颜色辨认。

## 布局

沿用现有稻田经营分析的主题式报告：左侧主题导航、主区域标题与 KPI、图表与解释、明细及口径。大屏主区域填满剩余宽度，不锁死 1830px。390px 窄屏变单列，横向滚动只限表格，不允许页面整体横向溢出。

图形选择对应分析问题，保留零基准与单位。比例不得与金额共用无说明坐标。条形适合排名和两期对照，瀑布适合增减构成，散点适合规模 / 变化关系，热图适合账号 × 渠道，哑铃适合前后比值。

## 功能契约

1. 范围切换：全部 / 剔除动态头部，更新限定区域的 KPI 和两个图。
2. 图表联动：点击账号排名、散点、热图或效率点，打开账号侧栏并高亮同名账号；历史页清除当前账号焦点。
3. 账号诊断：搜索、代理商与变化类型筛选、排序、指标组、当前筛选 CSV、同步详情选择器。
4. 五步讲解：全盘→剔除头部→消耗效率→目标→账号；前后按钮 / 方向键 / Esc，结束恢复原主题和范围。
5. 动效：数值渐变、页面入场、图表更新；支持显式关闭和系统 reduced-motion，不使用无限循环或遮挡阅读的特效。
6. 自适应：ResizeObserver 观察容器尺寸，宽屏与窄屏图表真实重绘。浏览器全屏也适用；不依赖固定截图比例。
7. 帮助与导出：功能指南、图例开关、悬停提示、当前主题打印、UTF-8 BOM CSV。

输出为单文件离线 HTML，内嵌 ECharts 6.0.0、Logo、样式、数据和脚本；不依赖 CDN、远程字体或第三方请求。ECharts 原始 LICENSE/NOTICE 随资产保留。

现有 Lieflat Charts 报告页面提供过风格参考；本技能不依赖其运行时，也不冒充其官方技能。已有样式在此固化并适配动态数据，不能只说“参考风格”却漏掉功能。
